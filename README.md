# الجدول اليومي - Study Focus

تطبيق أندرويد عربي للتركيز الدراسي والجدول اليومي.

## البناء

لبناء التطبيق محليًا:

./gradlew assembleDebug

## المتطلبات

- Android SDK 35
- Java 17
- Gradle 8.7

## الميزات

- واجهة عربية كاملة (RTL)
- سمة داكنة
- Jetpack Compose + Material 3
- بناء تلقائي عبر GitHub Actions
- نشر APK في Release تلقائي
